- Integrated NHTSA APIs for VIN decoding and vehicle specifications

End-to-end analytics pipeline processing data from **700+ NYC businesses** using Python and PostgreSQL.

Data analysis project exploring relationships between advertising channels and sales performance.

- Performed analysis using Python, Pandas, and statistical techniques
- Built visualizations with Matplotlib and Seaborn
- Compared advertising methods to identify relationships with sales performance
